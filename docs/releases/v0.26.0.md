# Phoenix OS 0.26.0

- **Released:** 2026-07-27
- **Status:** Accepted
- **Specification:** [RFC-0026](../rfcs/RFC-0026-secure-model-providers-and-inference-runtime.md)

Phoenix OS 0.26.0 adds an opt-in provider-neutral inference Runtime for trusted
Phoenix components that need bounded complete or streamed text-model inference.
The release preserves Phoenix OS 0.25.0 behavior when inference configuration is
omitted.

## Highlights

- Immutable Phoenix-owned request, response, chunk, usage, capability, limit,
  provider, model, and safe-error contracts isolate callers from provider SDKs.
- A reviewed `ModelProviderRegistry` admits only explicitly configured providers
  and models and rejects duplicates, mismatches, and unsupported capabilities.
- Every invocation requires exact central `model.infer` authorization for one
  concrete `model-provider:<provider>/model:<model>` resource.
- Exact versioned `SecretRef` leases and fail-closed endpoint policy keep
  credentials, destinations, DNS, TLS, redirects, and proxies outside caller
  control.
- `InferenceRuntime` enforces finite deadlines, first-byte and total-duration
  timeouts, byte, token, character, chunk, and concurrency limits.
- Streaming is ordered and bounded, exposes exactly one validated terminal
  record, and fails closed on malformed, missing, duplicate, extra, mismatched,
  or oversized provider output.
- Cooperative cancellation, bounded cleanup, no-transparent-retry semantics,
  content-free diagnostics, and Runtime-owned startup and shutdown preserve
  finite resource use.
- Maintainer Dashboard administration and optional concrete-resource
  service-account administration remain separate from model invocation
  authority.

## Security

- Inference is disabled by default and creates no implicit provider, model,
  endpoint, credential lease, policy grant, network permission, request,
  listener, or background worker.
- Model output is untrusted data. Text, streamed chunks, structured content,
  finish reasons, and usage metadata never authorize or execute capabilities,
  commands, jobs, workflows, plugins, webhooks, inbound events, filesystem,
  shell, network, or operating-system actions.
- Hosted endpoints require canonical HTTPS, certificate verification, complete
  DNS admission, pinned destinations, finite timeouts, disabled redirects, and
  disabled ambient proxies. Plain HTTP is limited to explicit all-loopback
  configuration.
- Credentials are leased immediately before provider execution and revoked
  after completion, failure, timeout, cancellation, or bounded shutdown cleanup.
- Prompts, responses, credentials, endpoint details, raw provider failures, and
  streaming frames remain excluded from safe administration, audit,
  observability, health, and lifecycle events.
- Complete execution, streaming, cancellation, admission, and administration
  fail closed when limits, exact authorization, security dependencies, or
  expected terminal state are absent.

## Compatibility and migration

Existing Phoenix OS 0.25.0 deployments gain no inference provider, model,
credential, endpoint, policy grant, service, route, or network authority merely
by upgrading. Existing service accounts receive no inference scopes or model
resources automatically. Inference configuration must be reviewed and enabled
explicitly.

See the staged
[v0.25.0 to v0.26.0 migration guide](../migrations/v0.25.0-to-v0.26.0-inference.md).

## Release validation

```bash
python scripts/check_webhook_release.py
python scripts/check_inbound_release.py
python scripts/check_inference_release.py
```

The inference gate reruns contracts, codecs, registry, authorization,
credentials, endpoint security, admission, complete execution, streaming,
cancellation, configuration, Runtime integration, administration, migration,
ADR, and release-metadata suites. It builds and inspects a wheel and sdist,
rebuilds a wheel from the sdist, and installs both wheels in isolated offline
environments without source-tree imports.

The full repository quality gate is:

```bash
ruff check .
ruff format --check .
mypy
pytest
python scripts/check_webhook_release.py
python scripts/check_inbound_release.py
python scripts/check_inference_release.py
```
