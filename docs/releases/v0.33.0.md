# Phoenix OS 0.33.0

**Released:** 2026-08-23

Phoenix OS 0.33.0 accepts RFC-0033, Effective Authority and Capability
Non-Amplification.

## Highlights

- Closed-world inventory of reviewed Phoenix-mediated protected operations and
  their canonical authority boundaries.
- Structural principal/session/agent/run subject binding and exact intent
  fingerprints.
- Fresh authority checks after untrusted waits, with fail-closed stale-session,
  stale-resource, cancellation, approval, and policy behavior.
- Composition and confused-deputy regression coverage proving that supported
  agent/tool/memory/workspace/host paths retain the final canonical boundary.
- Separately authorized, redacted, point-in-time inspect/explain diagnostics and
  a thin operator CLI.

## Security

Effective authority is an intersection, never a union. Data from prompts,
models, tools, memory, workspaces, clipboard state, labels, prior decisions, or
diagnostic output never manufactures authority. Unknown in-scope protected
operations fail closed.

Internal services cannot silently replace a requester with a stronger identity.
Cross-agent and cross-run authority borrowing is rejected by structural subject
binding. Inspection/explanation results are non-authoritative observations and
cannot be replayed as capabilities.

## Compatibility and migration

Phoenix OS 0.32.0 canonical subsystem authorizers remain in place. RFC-0033 does
not introduce a second policy engine and does not replace host, workspace,
memory, tool, inference, durable, coordination, identity, or control-plane
authorization.

See
`docs/migrations/v0.32.0-to-v0.33.0-effective-authority.md` for rollout and
rollback guidance.

## Release validation

The release must pass:

```bash
ruff check .
ruff format --check .
mypy
pytest
python scripts/check_authority_release.py
```

The dedicated gate reruns the RFC-0033 authority suite, validates release
hardening, builds and inspects wheel and sdist contents, rebuilds a wheel from
the validated sdist, and installs both wheel forms with `--no-deps --no-index`
before an isolated deterministic authority smoke test.

The complete GitHub Actions Python 3.12/3.13 matrix must be green for the exact
release commit.
